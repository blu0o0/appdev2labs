Lab 1 — Connecting Our System to a Cloud Database

ISU Anonymous Campus Discussion System • Supabase (PostgreSQL)

Goal

Move the database from local MySQL (XAMPP) to Supabase, a hosted PostgreSQL in the cloud, so the system works online for everyone.

Steps

  1. Create a project at supabase.com (region: Southeast Asia).
  2. SQL Editor → run supabase/schema.sql (MySQL schema converted to PostgreSQL: SERIAL keys, CHECK instead of ENUM, ON CONFLICT instead of INSERT IGNORE).
  3. SQL Editor → run supabase/seed.sql (topics, courses, campuses, demo accounts).
  4. Storage → create a public bucket named uploads for post images.
  5. Connect button → Pooler tab → copy the connection string.
  6. Put it in .env (never committed):
DATABASE_URL=postgresql://postgres.:@aws-0-ap-southeast-1.pooler.supabase.com:6543/postgres
SUPABASE_URL=https://.supabase.co
SUPABASE_SERVICE_ROLE_KEY=
SUPABASE_UPLOAD_BUCKET=uploads

Code change

Swapped the mysql2 driver for pg in db.js. To avoid rewriting every query, a translator converts MySQL ? placeholders to PostgreSQL $1, $2…, and INSERT … RETURNING id keeps result.insertId working:

const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
  ssl: { rejectUnauthorized: false }
});

Image uploads now go to Supabase Storage instead of a local folder.

Test

Run npm start — success looks like:

Connected to PostgreSQL (Supabase)
ISU Chatroom API running on http://localhost:3000
Login, posting, and image uploads all read/write the cloud database.

Important gotcha

Use the pooler connection (port 6543, username postgres.). The direct connection (db..supabase.co:5432) is IPv6-only and fails from cloud hosts with ENOTFOUND.
