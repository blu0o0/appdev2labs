Access Control

Select a user role and try to access the admin page.


Role Data

  • Student: Can view regular content but cannot access the admin page.
  • Admin: Has permission to access the admin page.

How It Works

Authorization (AuthZ) determines what a user is allowed to access based on their role or permissions.

Admin role: access granted. Student role: access denied.
Real applications must enforce permissions on the server.
